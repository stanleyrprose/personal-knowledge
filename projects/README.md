# Projects & Experiments

真实项目用于验证知识，而不是单纯记录项目进度。

当某项目对认知产生长期价值时，建立一个项目学习记录。建议结构：

- Problem / Goal
- Hypothesis
- Relevant Knowledge Nodes
- Decision Model
- Evidence
- Action / Experiment
- Result
- What Changed in the Model
- Boundary / Failure Conditions
- New Knowledge Gaps

只有能够改变或验证长期知识的项目经验才进入这里。日常 task log、流水账和短期状态应留在对应项目 repository。
